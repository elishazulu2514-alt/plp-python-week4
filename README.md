# PLP Python Week 4 Assignment

## Files Included
- `welcome.py`: Refactors repeated greeting code into a single reusable `welcome()` function.
- `toolbox.py`: Contains basic helper functions (`double`, `is_pass`, `greet`) demonstrating arithmetic, boolean comparisons, and default parameter values.

## Reflection
The hardest function to write was `greet` because ordering the default parameter `greeting` alongside the string concatenation required paying close attention to spacing and punctuation.
